# KB 검증 대시보드

`kb/winmate_kb.sqlite`를 브라우저에서 바로 검증하는 정적 페이지. 서버 없이 데이터 파일만 읽는다.

- 탭:
  - 개요: 적재 건수, 시나리오 테스트, 프로브, DR 커버리지, 세그먼트 대응
  - 질의: 요구사항→추천, 원문 검색, 이미지 검색, 업종 판별, 표현 인식
  - 컨텍스트 → 메시지: 업종·공간·제품·타겟고객·요구사항(모두 선택) → 헤드라인·핵심 메시지(+근거 문장)·제품 메시지·근거 사례(`query.py` E3)
  - 업종 장면: 장면 순서, 공간, 항목 해소, 원문 메시지
  - 제품: 역량 근거, 스펙, 태그, 추천 업종·공간
  - 도입사례, 이미지(등급 힌트), 메시지(원문 계층)
  - 검수
- 질의는 `src/engine.js`(= `build/query.py`를 옮긴 것)로 브라우저에서 계산한다. LLM은 쓰지 않는다.
- 컨텍스트 → 메시지 탭
  - 비워 둔 업종·공간·제품은 타겟고객·요구사항 문장에서 추론한다(가중치 0.5배). 해석 결과는 "해석한 컨텍스트" 표에 입력/추론으로 나오고, 추론값은 "입력으로 고정"으로 확정할 수 있다.
  - 점수 = Σ(가중치 × 일치도) ÷ Σ(쓴 항목 가중치). 가중치는 제품 0.35 · 업종 0.25 · 공간 0.2 · 타겟고객 0.15 · 요구사항 유사도 0.35. 막대 색이 항목별 기여다.
  - 처음 실행할 때 메시지 14,699개의 문장 벡터를 브라우저에서 계산한다(2~3초, 한 번만).
  - 문장마다 검수 표시는 "이 컨텍스트에 맞는 메시지인가"이며 `kind: ctxmsg`, `ctx.cm`(컨텍스트 입력)으로 저장된다. 검수 탭에서 "열기"를 누르면 같은 컨텍스트로 다시 뽑는다.
  - "묶음 CSV 내려받기"는 헤드라인·핵심 메시지·근거 문장·제품 메시지·사례 인용·KPI를 한 파일로 준다.
- 각 항목의 ✓ ✗ ? ✎ 표시는 claude.ai 아티팩트의 공유 저장소(`db` 컬렉션 `reviews`)에 저장된다.
  - 저장 형식: `{kind, id, label, ctx, verdict: ok|wrong|unsure, note, fix, by, at}`

## 다시 만들기

```bash
bash dashboard/run.sh          # export → golden → parity → build_site → smoke
```

| 단계 | 파일 | 하는 일 |
|---|---|---|
| 추출 | `export_data.py` | DB → `build/data/`의 JSON(gzip)과 벡터(float16 바이너리). 시나리오 테스트도 다시 돌려 결과를 담는다 |
| 기준 출력 | `golden.py` | Python `query.py`로 질문 57개와 컨텍스트 16개를 실행해 `build/golden.json`에 저장 |
| 일치 검사 | `parity.js` | 같은 질문을 JS 엔진으로 돌려 비교하고 `build/parity.json`에 저장(개요 탭에 표시) |
| 조립 | `build_site.py` | `src/page.html`에 엔진과 앱을 넣고 12MB 넘는 파일을 조각내 `site/`에 쓴다. 호스트가 바이너리를 받지 않으면 `--b64`를 쓴다 |
| 스모크 | `smoke.py` | 헤드리스 Chromium으로 모든 탭, 질의, 검수 저장, CSV를 확인하고 스크린샷을 `build/shots/`에 남긴다 |

`site/`는 정적 서버로 바로 열 수 있다. `index.html`은 문서 골격 없이 본문만 들어 있다(아티팩트 게시 형식). 로컬에서 볼 때는 `smoke.py`처럼 골격으로 감싸서 연다.

## 썸네일

claude.ai 페이지는 외부 이미지를 직접 불러오지 못한다. 그래서 미리보기는 데이터로 함께 싣는다.

- 만드는 곳: samsung.com 탭(같은 CDN이라 CORS 허용)에서 webp로 만든다.
  - 우선순위 3,384장은 176px로 만든다. 업종 항목, 사례 사진, 제품 대표 이미지, 특장점 A등급 등이고 목록은 `thumb_select.json`에 있다.
  - 나머지 KB 이미지는 160px로 만든다.
  - image-us.samsung.com의 20장은 CORS 때문에 만들지 못한다.
- 가져오는 방법: 탭에서 `WTHB` 묶음을 base64 청크로 넘긴다. `assemble_thumbs.py`가 청크를 모아 FNV 체크섬을 확인하고 `build/thumbs_pack*.bin`으로 쓴다.
- 대시보드용 변환: `export_data.py`가 `build/thumbs_pack*.bin` 전부를 2.5MB 묶음(`thumbs_NN.bin`)과 색인(`thumbs.json.gz`: 자산 id → 묶음, 위치, 크기)으로 다시 나눈다.
  - 묶음 순서는 제품군 대표 이미지 → 업종·솔루션 → 도입사례(문서별) → 상품 상세(제품군별) → US다.
  - 화면은 보이는 썸네일이 든 묶음만 받는다.
- 썸네일이 없는 이미지는 카드에 "원본 열기" 링크가 나온다.
