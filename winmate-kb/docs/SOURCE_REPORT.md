## 2. 수집하면서 확인한 사이트 특성(빌드에 반영)

- 상품 목록 API 가 돌려주는 필터값 중 일부는 필터 패널에 없고, 그 값으로 조회하면 목록 전체가 그대로 돌아온다(예: 사이니지의 `flip`, `built-in-wifi`, 세탁기의 `black`). 이런 필터 32개는 소속 태그로 쓰지 않았다(빌드 메모에 목록이 남는다).
- 솔루션(링크 클라우드, b.IoT, MagicINFO, VXT 등)은 사이트에서 상품 코드로도 판매된다. 솔루션 엔티티와 상품 카드를 `SOLD_AS` 엣지로 잇고, 링크 해소는 솔루션을 우선한다.
- 시스템에어컨 일부 상품은 목록 분류(중소건물용·대형건물용)와 비교 분류(`dvms-indoor` 실내기, `dvms-outdoor` 실외기)가 다르다. 업종 페이지는 비교 분류 목록(`dvms-indoor/all-dvms-indoor`)으로 링크하므로 비교 분류도 카테고리로 만들었다.
- 업종 페이지는 PC/모바일 섹션을 모두 HTML 에 담는다. 모바일 섹션은 공간 라벨이 하나씩 나뉘어 있어서, 같은 제목의 섹션을 합칠 때 항목 단위 공간(`item_space_label`)으로 쓴다.
- 상품 상세 이미지는 지연 로딩이라 `src`는 자리표시 이미지이고 실제 주소는 `data-src`에 있다. alt 문장이 장면을 자세히 서술한다(예: "호텔의 객실 침대 정면 벽면에 호텔TV가 설치되어 있고…"). 이 문장으로 공간과 1차 이미지 등급을 정했다.
- 도입사례 페이지 `<title>`은 모두 같아서 본문 h2(사례 제목)를 문서 제목으로 쓴다. 하단 '관련 제품' 링크가 사이트가 직접 밝힌 사용 제품이다.
