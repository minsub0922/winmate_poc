MagicINFO Author
템플릿 · 클립아트 · 시각 효과를 조합해 콘텐츠를 만들고, HTML · CSS · JS 요소도 코딩 없이 넣습니다.
MagicINFO Server
재생 목록에 담아 날짜 · 시간별로 예약 배포하고, 연결된 기기를 실시간 모니터링 · 원격 제어하며 통계를 봅니다.
MagicINFO Player
8K 화질과 멀티스크린 동시 재생을 지원하고, 거의 모든 웹 표준 콘텐츠를 재생합니다.
MagicINFO Datalink
외부 데이터를 콘텐츠에 연결하는 기능 (공식 기능 목록 기준).
